# Calculadora en Python

## Descripción
Me puse como desafío crear una calculadora simple con conceptos de manejo de errores en Python. 

## Funcionalidades
- Suma, resta, multiplicación y división.
- Potencia.
- Manejo de errores con excepciones.

## Conceptos aprendidos
- try y except
- ValueError y ZeroDivisionError
- else y finally
- raise

## Cómo ejecutar
1. Descargar archivo ejercicio_manejo_errores.py
2. Tener Python 3 instalado
3. Ejecutar en terminal python ejercicio_manejo_errores.py
